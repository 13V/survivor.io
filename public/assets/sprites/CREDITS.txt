PLAYER: HD "Survivor" character (true 8-direction top-down) from the supplied pack
"FREE Character HD Survivor W Bike". Each animation is a 14-frame x 8-direction grid of
128px cells, sliced at runtime into directional rows (src/game/survivorSprite.ts). The
player faces its aim direction (nearest enemy, else movement) by picking the matching
direction row -- no flipping. States: Idle, Run, TakeDamage. The bike (RideRun) drives a
short dash ability (tap the on-screen button or Space/Shift) with i-frames + cooldown.
Sheets live in assets/sprites/survivor/.

ENEMIES: HD "2D Zombie Pack 1" (same creator/format as the survivor). Character sheets are
15-frame x 8-direction grids (cell = width/15); bundled at a uniform 64px cell (downscaled
to 960x512) to keep GPU memory mobile-safe (~120MB). 20 zombie types are grouped into pools
matching the four enemy classes (texKind 0=walkers, 1=fast, 2=brutes, 3=bosses); each spawn
picks a random type, and named bosses get a signature type (ZOMBIE_BY_ID). Animations:
  - Run     : 8-direction walk, facing the player.
  - Attack1 : 8-direction melee, played when a zombie is within reach of the player.
  - Die     : one-shot death; the sprite is handed off to it and fades out.
Acid/Blood are 15-frame FX strips (zombies/_fx/): Blood splatters on every zombie death,
Acid bursts on exploder deaths and where enemy (spitter) shots hit the player. Sheets in
assets/sprites/zombies/<Type>/{Run,Die,Attack1}.png, sliced at runtime
(src/game/zombieSprite.ts). Easy to extend -- drop sheets in and edit ZOMBIE_POOLS /
ZOMBIE_BY_ID. The source pack also ships Walk/Attack2-5/Idle/Taunt/WakeUp/CrouchRun and
~16 more zombie types, not yet wired.

OTHER: projectiles, blades, gems and the flat mauve ground are procedurally generated
(src/game/textures.ts). The procedural cartoon hero + pixel zombie remain as fallbacks if
the HD sheets are absent. Filtering: HD sheets = linear, pixel zombie = nearest.

History note: earlier third-party art was used during development and removed; it still
exists in git history, so keep this repository private until the history is scrubbed if
you intend to make it public.

Enemy sprites (the zombie horde across all three kinds + boss) are an animated
pixel-art zombie supplied by the project owner as an Aseprite file (Zombie.aseprite).
Its Run-cycle frames (8) were extracted to PNGs and drive an 8-frame walk animation:
  enemy0/1/2.png, boss.png  <- Run frame 0 (static base)
  z0_*/z1_*/z2_*.png         <- Run cycle frames 0-7

The player hero, projectiles, blades, gems and the flat mauve ground are procedurally
generated at runtime (flat survivor.io-style cartoon) in src/game/textures.ts.

The loader (src/game/assetPack.ts) overrides each character slot independently, so any
slot without a PNG falls back to its procedural art. Sprites are nearest-filtered.

History note: earlier third-party art was used during development and removed; it still
exists in git history, so keep this repository private until the history is scrubbed if
you intend to make it public.

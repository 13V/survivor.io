In-game character sprites (player, zombies, boss) are 3D models generated with
Meshy AI (https://www.meshy.ai/) from text prompts, then rendered top-down to 2D
sprites and stylised (flat toon shading + posterise + bold outline). They were
generated under this project's own Meshy account, whose owner holds the commercial
rights to the generated assets.

Mapped into the game (baked to each slot's footprint, linear-filtered):
  player.png  <- hero (blue-cap survivor)
  enemy0.png  <- green zombie (basic)
  enemy1.png  <- lanky zombie (fast)
  enemy2.png  <- brute zombie (tank)
  boss.png    <- brute zombie (boss)

Projectiles, blades, gems, weapon VFX and the flat mauve ground are procedurally
generated. The previous third-party pixel pack has been removed from the working
tree (note: it still exists in git history, so keep this repository private until
that history is scrubbed if you ever intend to make it public).

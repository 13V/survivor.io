PLAYER: HD "Survivor" character (true 8-direction top-down) from the supplied pack
"FREE Character HD Survivor W Bike". Each animation is a 14-frame x 8-direction grid of
128px cells, sliced at runtime into directional rows (src/game/survivorSprite.ts). The
player faces its aim direction (nearest enemy, else movement) by picking the matching
direction row -- no flipping. States: Idle, Run, TakeDamage, and Die (a death sequence
plays the survivor's Die animation before the game-over card). The bike (RideRun) drives a
short dash ability (tap the on-screen button or Space/Shift) with i-frames + cooldown.
Sheets live in assets/sprites/survivor/.

ENEMIES: HD "2D Zombie Pack 1" (same creator as the survivor), all 36 zombie types, each
with SIX animations: Run, Walk, Attack1, Attack2, Die, Die2.

  Memory trick (src/game/zombieSprite.ts + tools that produced assets/sprites/zombies/):
  loading every animation as full 8-direction sheets would be ~1GB of GPU memory. Two
  facts make it tractable: (1) top-down characters are horizontally symmetric, so only 5
  directions are stored (E, SE, S, N, NE) and W/SW/NW are rendered as horizontal mirrors;
  (2) each sheet is mostly empty padding (~5% filled for Run), so every sheet is cropped
  to the figures' bounding box. A per-sheet feet-line (atlas.json) is baked so the crop is
  invisible -- the sprite is scaled by the ORIGINAL cell and anchored by the baked Y, so
  feet stay planted. Result: 6 animations x 36 types in ~120MB instead of ~1GB.

  Behaviour: a random type per spawn from the class pool (texKind 0=walkers, 1=fast,
  2=brutes, 3=bosses); named bosses get a signature type (ZOMBIE_BY_ID). Slow movers
  shamble (Walk), faster ones Run; they swing a random Attack variant when in reach of the
  player; on death the sprite is handed to a random Die variant that fades out. Acid/Blood
  FX strips (zombies/_fx/): blood on death, acid on exploder deaths + where enemy (spitter)
  shots hit you. More animations exist in the pack (Idle/Taunt/WakeUp/CrouchRun/Attack3-5/
  Idle2) and can be added the same way.

OTHER: projectiles, blades, gems and the flat mauve ground are procedurally generated
(src/game/textures.ts). The procedural cartoon hero + pixel zombie remain as fallbacks if
the HD sheets are absent. Filtering: HD sheets = linear, pixel zombie = nearest.

History note: earlier third-party art was used during development and removed; it still
exists in git history, so keep this repository private until the history is scrubbed if
you intend to make it public.
